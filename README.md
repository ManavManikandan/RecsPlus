# RecsPlus

RecsPlus is a music recommendation web app that helps you discover new tracks based on your listening preferences. Built with Flask, the app integrates with the Spotify Web API to deliver personalized recommendations and music insights.

Features

🎧 Get personalized song recommendations

🔍 Search for artists, tracks, or genres

📊 Explore track metadata (energy, danceability, tempo, etc.)

🖼️ Simple and clean web UI

🔑 Secure Spotify API integration

🛠️ Tech Stack
* Backend: Python, Flask
* Frontend: HTML, CSS, Jinja templates
* APIs: Spotify Web API and Gemini API
* Deployment: Render
